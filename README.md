# Readdy

**Smart reading and contextual translation for documents.**

Readdy is a browser-based reading workspace designed to make working with multilingual documents more accessible. Its interface supports Arabic right-to-left reading alongside English and French content.

## Highlights

- Document-oriented reading interface.
- OCR-powered text extraction workflow.
- Context-aware reading and translation experience.
- Light and dark themes.
- Responsive layout for different screen sizes.

## Getting started

1. Clone this repository.
2. Open `index.html` in a modern browser.
3. Allow the required browser capabilities when prompted.
4. For OCR and document processing, ensure the configured third-party libraries can load.

## Technologies

The current front end references browser-based libraries including PDF.js, Mammoth.js, and Tesseract.js.

## Security and privacy

Only open documents you are authorised to access. Avoid uploading confidential documents to services you do not trust. Do not commit credentials or private data.
